# DSH ACP Agent Hub 安装说明

适用于 Windows 官方 DeepSeek Harness Desktop **0.2.2-rc.1**，插件版本 **0.3.0**。把本说明和 `dsh-acp-agent-hub-0.3.0.tgz` 一起发给使用者。每位使用者在自己的电脑上准备并登录要用的智能体，可以只用其中一个。

## 准备智能体

- **Codex** 需要 Node.js 和已登录的 Codex。先在 PowerShell 运行 `node --version`，确认能启动 Node（已用 24.x 验证）。插件内含 ACP 适配器，会优先检测已有的 Codex Desktop CLI，也支持从 `PATH` 使用 `codex` 命令。如果尚未安装 Codex Desktop 或 CLI，可运行 `npm.cmd install -g @openai/codex` 安装 CLI，再运行 `codex login`。[Codex ACP 文档](https://github.com/agentclientprotocol/codex-acp#installation)
- **Qoder** 使用 Qoder CLI 的登录态。若 CLI 位于 Windows 默认安装目录，可用 PowerShell 登录。[Qoder CLI ACP 文档](https://docs.qoder.com/cli/acp)

```powershell
& "$env:USERPROFILE\.qoder\bin\qodercli\qodercli.exe" login
```

- **WorkBuddy** 使用 WorkBuddy 桌面版随附的 CLI（默认 `C:\Program Files\WorkBuddy\resources\app.asar.unpacked\cli\bin\codebuddy`），插件会自动探测，也可用 `DSH_ACP_WORKBUDDY` 指定。桌面版只带精简 bundle，插件会自动改用 `--serve --acp --acp-transport stdio --port 0` 并注入 `CODEBUDDY_FORCE_LITE_WB_BUNDLE=1`，因此每条连接还会在 `127.0.0.1` 的随机端口短暂启动一个带密码的本地 HTTP 服务。

  WorkBuddy CLI 的登录态和桌面版是分开的。未在 CLI 侧登录时，插件能读到模型列表，但每轮回复会以 `refusal` 结束；请先在 CLI 侧完成登录，或设置 `CODEBUDDY_AUTH_TOKEN` / `CODEBUDDY_API_KEY` 环境变量后再启动 DSH。

## 安装和使用

1. 保留下载的 `.tgz` 文件。在 DSH 桌面版打开「插件」→「添加插件」。若升级已有版本，先在插件页卸载旧版。
2. 在「包名或地址」粘贴 `.tgz` 文件的完整路径，点「安装」。安装时 DSH 会从 npm 获取依赖。安装成功后点「立即启用」，并按界面提示重启。
3. 打开工作区和会话，在输入区右下角打开模型菜单，选择 Codex、Qoder 或 WorkBuddy 下的具体模型。
4. 回复过程中，智能体的思考过程会以「思考」块出现，可以展开查看；不需要的话在插件配置里设 `showThoughts: false`。

## 只显示 Default model

这表示 DSH 尚未从该智能体读到模型目录。先确认安装的版本是 **0.3.0**，并检查 Node 和对应的 CLI 登录。如果使用了自定义安装位置，可在 Windows 用户环境变量里指定完整路径，然后从系统托盘退出 DSH 再重新打开。

| 变量 | 用途 |
| --- | --- |
| `DSH_ACP_NODE` | 自定义 `node.exe` 完整路径 |
| `DSH_ACP_CODEX_ENTRY` | 自定义 Codex ACP 的 `dist/index.js` 完整路径。默认使用随插件安装的适配器 |
| `CODEX_PATH` | 指定要使用的 `codex.exe` 完整路径，优先于自动检测 |
| `DSH_ACP_QODER` | 自定义 `qodercli.exe` 完整路径 |
| `DSH_ACP_WORKBUDDY` | 指定 WorkBuddy `codebuddy` 启动脚本或可执行文件，优先于自动检测 |
| `CODEBUDDY_AUTH_TOKEN` / `CODEBUDDY_API_KEY` | 透传给 WorkBuddy CLI 的凭据 |

如果之前在 DSH 配置中手动覆盖过 `acp-agent-hub` 的启动参数，该覆盖会继续生效。要使用新包的自动检测，可移除这条自定义配置后重启 DSH。

## 这一版的能力边界

支持文字对话、流式回复、思考过程展示、模型切换和同一 DSH 会话内续聊。每轮用 DSH 可见文本历史创建提示；连接和 ACP 会话在空闲一段时间后回收。`released` 接入方式下，DSH 的工具、技能不桥接给外部 CLI，外部 CLI 使用自己的权限配置，插件拒绝经 ACP 发起的原生工具审批。附件（图片/文件）暂未接入。需要工具桥接时改用 `driver` 接入方式，并要求智能体支持 HTTP MCP。
